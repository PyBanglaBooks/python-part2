# পাইথন দিয়ে প্রোগ্রামিং শেখা – দ্বিতীয় খণ্ড

তামিম শাহ্‌রিয়ার সুবিনের লেখা *পাইথন দিয়ে প্রোগ্রামিং শেখা – দ্বিতীয় খণ্ড* বইয়ের সব প্রোগ্রাম এখানে রাখা আছে। প্রতিটি অধ্যায়ের প্রোগ্রাম আছে আলাদা ফোল্ডারে, যেমন `ch05` ফোল্ডারে আছে অধ্যায় ৫–এর প্রোগ্রামগুলো। ফাইলের নাম বইয়ে যেমন দেওয়া আছে, এখানেও তেমন।

এখান থেকে প্রোগ্রাম কপি করার উদ্দেশ্য হচ্ছে নিজের লেখা প্রোগ্রাম মিলিয়ে দেখা, টাইপ করার কষ্ট বাঁচানো নয়। বইয়ের প্রতিটি প্রোগ্রাম নিজে টাইপ করে রান করে দেখতে হবে। শুধু বই পড়ে গেলে কিংবা কপি-পেস্ট করলে প্রোগ্রামিং শেখা যাবে না।

প্রোগ্রামগুলো পাইথন 3.12 ও তার পরের সংস্করণে পরীক্ষা করা হয়েছে।
